Task briefBEGINNER · 10 MIN

Fix the function

Implement sum_numbers(numbers) so it returns the sum of the numbers in a list.

Expected behaviour

  • sum_numbers([2, 3, 4]) → 9
  • sum_numbers([-2, 2]) → 0
  • sum_numbers([]) → 0
  • sum_numbers([7]) → 7

Validation & trust

Learn before scaling.

First, prove the workflow is useful and understandable to real candidates and hiring teams.

↗

Recruiter interviews

Ask 5–8 hiring managers what current assessments fail to explain.

▤

Report usability

Check whether reviewers can understand evidence, strengths, and unresolved issues.

◇

Pilot commitment

Find a team willing to test the prototype and give structured feedback.

Trust principles: use consistent criteria, protect candidate data, explain limitations, and keep the final hiring decision with a human reviewer.
